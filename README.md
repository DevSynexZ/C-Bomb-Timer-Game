A simple **time-counting bomb game** built in **C** for fun while practicing programming basics.  
Developed and tested in **VS Code terminal**.

---

## 🎮 Features
- Countdown timer simulation  
- "Bomb" message when the timer reaches zero  
- Practice with **loops, conditionals, and delays** in C

- There's a puzzle for the password to defuse the bomb.
